# GR4DP - Production-Ready Distributed AGI System

## Overview
This repository contains a complete implementation of the GR4DP framework. It integrates:
- A decentralized ledger and P2P network (memory, M).
- Parallel Self-Model (S) and World-Model (W).
- Proof-of-Space-and-Time consensus for block creation.
- An Executive orchestrator that merges S and W into consciousness (C).
- A minimalist web UI for hosting the node and chatting with the system.
- **Hierarchical knowledge commits**, ensuring knowledge is organized, prioritized, and can be validated logically and empirically.

## Quick Start
1. **Build**:
   ```bash
   docker build -t gr4dp .
   ```
2. **Run**:
   ```bash
   docker run -p 4000:4000 -p 4001:4001 -p 8000:8000 gr4dp
   ```
